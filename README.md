# 🎮 Rock Paper Scissors

A simple **Rock Paper Scissors game built using Python** where the player competes against the computer.

## 📌 About the Project

This is a beginner-friendly Python game created to practice:

* Python basics
* Conditional statements
* Loops
* Functions and variables
* Random number generation
* User input
* Basic game logic
* Git and GitHub

The game allows the player to choose **Rock, Paper, or Scissors**, while the computer makes a random choice. The winner is decided according to the standard Rock Paper Scissors rules.

## 🎯 Features

* 👤 Player vs Computer
* 🤖 Computer makes a random choice
* 🪨 Rock, 📄 Paper, and ✂️ Scissors
* 🏆 Score tracking
* 🤝 Draw tracking
* 🔄 Multiple rounds
* 🎯 First player to reach 5 points wins
* ❌ Handles invalid input

## 🕹️ How to Play

Choose one of the following options:

```text
1. Rock
2. Paper
3. Scissors
```

The computer will randomly select its choice.

### Winning Rules

```text
Rock     → beats Scissors
Paper    → beats Rock
Scissors → beats Paper
```

If both players choose the same option, the round is a draw.

The game continues until either the player or the computer reaches **5 points**.

## 💻 Requirements
